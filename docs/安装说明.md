# WPS 一键排版 · Mac 安装说明

## 安装

1. 安装 Mac 版 WPS Office。当前版本面向 Apple 芯片 Mac，要求 macOS 13 或以上。
2. 保存文档并完全退出 WPS（菜单「WPS Office → 退出」）。
3. 打开 DMG，双击「WPS一键排版」应用，选择「安装 / 更新」。无需拖到应用程序目录，无需管理员密码、Python 或编译工具。
4. 若 macOS 提示访问其他应用数据，请自行核验并处理系统授权。安装程序需要读写 WPS 插件注册文件；不授予时不能完成安装或卸载。
5. 出现「安装完成」后重新打开 WPS 文档，顶部出现「一键排版」。可推出磁盘映像。

此测试版采用本地签名，未通过 Apple 公证。下载后可能受到 Gatekeeper 限制；请按系统允许的流程核验来源并由本人决定是否打开。不要关闭系统安全保护。如果系统不允许打开，请使用源码构建或等待正式签名版本。

## 使用

进入「排版设置」，选择模板、调整设置并保存。回到文档点击「一键排版」才修改文档；点「排版结果」查看完整结果或错误。检查后自行保存；⌘Z 撤销整次排版。

落款段数在「落款」顶部，可选无落款、1/2/3 段或输入 0～99 段。按回车形成的非空普通段落计数，空行及自动换行不计；每个模板可保存不同的范围、字体、字号、对齐和缩进。开启「全篇段落」统一格式时，行距和段距由全篇设置决定；关闭统一后可单独调整。

页眉、页脚文字及页码默认关闭。启用的部分会替换文档原有内容。首页不显示仍计入页数；起始值 1 时第二页为 2。页脚文字和页码分两行，多节连续编号。字体留空沿用对应区域字体。

奇偶页不同、复杂对象或无法安全分离的页脚会在修改前提示，不自动改变这些结构。

## 更新和卸载

更新：退出 WPS，打开新版安装程序，选择「安装 / 更新」。模板会保留。

卸载：退出 WPS，再打开安装程序选择「卸载插件」。移除登录服务及本插件注册，保留模板和应用副本，便于以后恢复。其他 WPS 插件不受影响。

本机位置：
- 应用及模板：`~/Library/Application Support/WPSLocalFormatter/`
- 模板文件：该目录的 `settings.json`
- 登录服务：`~/Library/LaunchAgents/local.wps.formatter.background.plist`

## 排查

- 看不到工具栏：确认打开的是文字文档，完全退出并重开 WPS；仍未出现时重新安装修复注册。
- 服务无法启动：查看应用目录的 `service-error.log`，检查本机端口 38941 是否被占用。安装程序会尝试恢复旧版本。
- 缺少字体：在设置中选择本机已有字体，或自行安装有合法授权的字体。本项目不附带字体。
- 无法使用页眉页脚：阅读具体提示；复杂文档先使用 WPS 自带功能处理，不要反复重试。
- 安装失败：保留错误提示和日志。请勿公开文档内容、个人路径或模板中的内部文字。

本工具仅在本机监听 `127.0.0.1:38941`，不上传文档，不包含云服务。
