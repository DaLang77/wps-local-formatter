# WPS 一键排版 · ZIP 版使用说明

## 准备与初始化

要求 Apple 芯片 Mac、macOS 13 或以上、Mac 版 WPS 和 Node.js **22 或 24 LTS**。从 [nodejs.org](https://nodejs.org/) 官方来源准备 Node；已安装的有效版本可直接使用。

1. 解压 `wps-local-formatter-1.2.0-beta.1-arm64.zip` 到普通目录。
2. 保存需要保留的文档，从 WPS 菜单完全退出；只关闭文档窗口不等于退出。
3. 双击「初始化.command」，或在解压目录运行 `node node-host/cli.mjs init`。安装 Node 或解压 ZIP 后仍需运行这个入口。无需编译、npm 安装或手改注册文件。终端明确显示“初始化的本地操作已完成”才表示切换成功；显示“未完成”时，处理上方错误后重试，窗口会保留错误并等待回车。
4. 若 macOS 请求访问 WPS 应用数据，请本人核验并处理正常授权；拒绝时初始化会报告失败，不关闭系统保护，也不自动关闭 WPS。
5. 初始化完成后打开 WPS 文字文档。功能区「一键排版 → 环境检查」须分别确认本地服务、连接、API、文档和字体；本地服务成功不等于插件可用。

ZIP 中的 `.command` 入口按 macOS 正常流程打开。系统若限制打开，请核验下载来源并由本人决定；不需要 Developer ID 或 Apple 公证，不要求关闭系统安全保护。

初始化记录有效的绝对 Node 路径并设为登录自动启动。以后只需在 WPS 内操作；解压目录可保留用于检查或维护。更换/移走 Node 后重新初始化修复路径。切换服务可能等待端口释放，最长 60 秒；不要同时运行多个初始化入口。

## 使用

在「排版设置」选择模板并保存；回到文档点击「一键排版」才修改。自动识别方式在「识别与分页 → 段落识别方式」，可选沿用首尾判断或优先样式/大纲层级。顶部「文档结构」显示每段摘要、识别角色和依据，可人工纠正标题、正文等角色并查看改动清单。「此段保持原样」排除全部属性写入。

旧模板升级后继续沿用首尾判断。点击「新建模板」使用优先样式/大纲层级等新默认；「另存为模板」保留当前草稿中的识别方式和格式选择。

若设置页仍只有标题、正文、落款、全篇段落、页面、页眉页脚六个标签，且顶部没有「文档结构／环境检查」，当前页面仍是旧版。先在本次解压目录运行「环境检查.command」；提示“当前候选尚未切换”时保存并退出 WPS，重新初始化再打开。若本地候选已一致而页面仍旧，保存并完全退出 WPS 后重开，以清除旧页面缓存。

范围默认为整篇；选中段落模式即使只选部分文字也处理整个段落。空选区、页眉页脚、文本框或纯表格选区会停止，不扩大到整篇。选区模式不改页面、页眉页脚及页码，自然分页可能随格式变化。

人工标记不持久保存。关闭/切换文档或修改文字、拆合段落后清除；再次排版前在文档结构重新检查。多级标题不重新套样式；列表保护不重建编号模板。

排版后检查真实结果，自行保存；⌘Z 撤销整次修改。长段/长落款可能超过一页；分页选项只表达尽量保持，不强制串联整篇。

## 提取、导入与分享

把光标放入一个普通正文段，在设置中选择目标角色并点击提取。部分文字选区仍提取完整所在段；跨段、表格和非正文拒绝。混合格式或不能表达的值变为保持原样。只填草稿，不改文档、不保存模板。全篇统一启用时仍覆盖角色行距和段距。

导出当前单个模板为 JSON。默认清除页眉页脚文字，同时关闭这两个开关；需要分享内部文字时显式勾选。JSON 不包含内部 ID、文档信息、启动令牌或人工标记。导入完整校验后追加；同名须改名，不自动选择、保存为当前设置或排版。

## 更新、回退与卸载

- 更新：退出 WPS，解压新版 ZIP，重复运行「初始化.command」。先候选自检、再备份并切换；安装不改变现有设置。
- 检查：双击「环境检查.command」，或 `node node-host/cli.mjs check`；进入 WPS 的环境页核对实际连接。
- 回退：退出 WPS，运行「回退.command」。恢复本插件上次初始化前的注册/登录项，保留其他插件后来新增或更新的注册。回到旧 Swift 服务时，先另存新配置，再恢复本次对应的旧版兼容配置快照；新模板留在备份中，旧 App 不删除。
- 卸载：退出 WPS，运行「卸载.command」。移除本插件注册和登录服务，保留设置、候选运行目录、备份及旧 App；其他插件不受影响。

失败或中断后不要手工覆盖备份。退出 WPS，再运行初始化恢复未完成事务；若恢复也失败，按错误给出的备份位置核对。

本机位置：

- 设置、运行目录与事务备份：`~/Library/Application Support/WPSLocalFormatter/`
- 设置：该目录 `settings.json`；首次 v2 保存的兼容备份为 `settings.json.legacy-v1.backup`
- 登录服务：`~/Library/LaunchAgents/local.wps.formatter.background.plist`
- WPS 注册：WPS 沙箱的 `.kingsoft/wps/jsaddons/publish.xml`

## 具体故障处理

| 状态 | 处理 |
| --- | --- |
| 端口 38941 被占用 | 运行检查入口；核对占用进程来源，不关闭未知进程。错误恢复后重新初始化。 |
| 系统数据访问被拒绝 | 由本人在系统设置核验相关程序访问授权，再重试；原设置和备份保留。 |
| 注册异常 | 阅读 XML 结构或权限错误；退出 WPS 后重新初始化。不要手工删除其他插件。 |
| 服务/API/插件版本不一致 | 退出 WPS，重新初始化新版，再重新打开文档清除旧脚本缓存。 |
| 未取得字体列表 | 显示“等待连接”，先使 WPS 插件接口就绪，不能据此判定缺字体。 |
| 已确认缺字体 | 在环境页从本机字体选择并显式保存，或自行安装合法字体后重开 WPS；不静默替换。 |
| 只读、保护或修订模式 | 在 WPS 处理对应状态，或使用可编辑副本。 |
| 自动撤销失败 | 停止继续排版，在 WPS 核对并手动撤销；不要把成功提示当作恢复证据。 |

本工具不上传文档；诊断或错误反馈请脱敏，不公开真实文档、模板内部文字、日志路径或令牌。当前实测范围与未完成项见 [验证记录](验证记录.md)。
