# 开源发布

公开仓库：[DaLang77/wps-local-formatter](https://github.com/DaLang77/wps-local-formatter)。源码和项目图形采用 MIT。

新版本候选为 `v1.2.0-beta.1`：插件 ZIP、源码 ZIP、使用说明和 SHA256 清单。仅在五项功能及计划规定的实际验收完成后，创建一次统一预发布；当前候选不代表 Release 已发布。历史 [v1.1.0-beta.4](https://github.com/DaLang77/wps-local-formatter/releases/tag/v1.1.0-beta.4) 的 DMG/tag/资产保留不变。

## 打包和检查

维护流程使用 [github-open-source-release](../skills/github-open-source-release/SKILL.md) 及仓库项目参考。

```sh
npm ci --ignore-scripts
node --test tests/*.test.cjs
node node-host/cli.mjs selftest
bash scripts/package.sh
python3 tests/verify-package.py
```

默认构建为 Node ZIP，唯一运行依赖随包包含、锁定版本并保留 MIT 声明。普通用户准备 Node 22 或 24 LTS，无需编译或安装 npm 包；不构建新 App/DMG，不要求 Developer ID 或 Apple 公证。

浏览器检查在独立 CI job 中安装固定 Playwright 开发工具，不进入运行 ZIP。Swift 历史事务测试继续保留。自动检查不启动 WPS，不提供实际文档/全新系统用户验收证据。

`release/` 生成：

- `wps-local-formatter-1.2.0-beta.1-arm64.zip`
- `wps-local-formatter-1.2.0-beta.1-source.zip`
- `wps-local-formatter-1.2.0-beta.1-SHA256SUMS.txt`

归档采用白名单，不包含个人文档、配置、日志、字体、缓存、本地 evidence 或设计草稿。源码包保留文档、真实页面合成截图、CI、测试、许可、贡献说明和可复用发布 skill。校验脚本逐文件核对源码字节、运行包、许可证和 SHA256。安装说明同时随运行 ZIP 分发。

## 发布门槛

发布前核对 [验证记录](验证记录.md)。真实 WPS 必须完成格式回读、正文/排除区域/编号保护、选区外属性、重复执行及一次撤销；全新系统用户、更新、回退、卸载、权限拒绝、启动失败和中断恢复必须分别记录，不把隔离目录模拟替代实机。

验收通过后明确暂存路径、审查公开差异，提交/push并读取该提交 CI。新 tag 指向通过的提交，预发布资产英文名称不覆盖历史版本。上传后读取公开 Release、资产尺寸和无需登录的下载结果，下载哈希与本地一致、源码内容与 tag 一致。
