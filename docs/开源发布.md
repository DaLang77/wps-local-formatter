发布物：DMG、source.zip、SHA256SUMS.txt；当前 `v1.1.0-beta.4` 标记为预发布版本。下载见 [发布页](https://github.com/DaLang77/wps-local-formatter/releases/tag/v1.1.0-beta.4)，安装与已验收范围见 [安装说明](安装说明.md) 和 [验证记录](验证记录.md)。

## 维护者打包

后续开源维护使用 [github-open-source-release](../skills/github-open-source-release/SKILL.md)。仓库内保留 skill 源文件，供其他维护者复用；本机可将该目录安装到 Codex 的 skills 目录。README 的三张图片来自实际设置页面及合成配置，可通过 `node scripts/capture-demo-images.cjs` 重建（可选开发依赖 `playwright`，需 Google Chrome）。

也可单独安装发布 skill：

```sh
npx skills add https://github.com/DaLang77/wps-local-formatter --skill github-open-source-release --global --agent codex
```

仅更新文档、示例图片或发布流程时，推送源码并检查 GitHub CI 即可，不升级应用版本、不改写已有发布资产。后续应用版本的源码包会包含图片、skill 和项目维护说明。

运行 `bash scripts/package.sh` 生成安装包、白名单源码包与校验文件。发布文件使用英文名，避免 GitHub 改写中文名后导致校验清单失效；应用内仍显示中文名称。不要上传整个工作目录；本地 `evidence/` 可能包含用户配置、历史文档快照和个人路径。Git 忽略验收数据、设计草稿、文档、字体、配置、构建缓存及发布资产；发布资产通过 GitHub Release 分发。

新增公开文件时须检查是否包含个人信息；Git 忽略规则无法替代内容检查。发布前核对校验值、源码包与发布提交的一致性。源码包必须包含许可证和贡献说明。

## 测试版边界

当前尚未完成独立 Mac / 全新系统用户的安装、更新、卸载及 WPS 兼容验收。发布测试版时须保留该说明；正式稳定版发布前补齐这些验证。若需要消除常规下载后的 Gatekeeper 阻碍，应使用项目维护者的 Apple Developer ID 签名并提交公证；当前脚本只做本地签名，不包含凭据。

本仓库不分发 WPS、字体文件或用户文档，不代表 WPS 官方产品。
