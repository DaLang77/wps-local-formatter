## 1.2.0-beta.1 候选 · 2026-10-03

五项功能代码已实现：文档结构与人工纠正、整篇/选区、九级标题/分页/列表保护、格式提取/模板 JSON 分享、Node 服务和初始化事务。旧模板读取只在内存迁移，安装不改配置；新模板采用新默认。

已取得的证据：

- Node 22 本机自动回归 152 项通过，零跳过（含 15 项浏览器检查、26 项 HTTP 主机检查）；覆盖既有配置/正文/页眉页脚回归，以及 v2 配置、选区边界、标记失效、完全跳过、空段分页、严格布尔回读、编号保护、导入导出、HTTP 防护和安装失败回退。
- 15 项实际页面/合成接口浏览器测试通过，包括 420px 布局、空段纠正、保留草稿、提取不保存、同名导入改名、默认分享去除内部文字、字体等待和显式保存，以及窗口绑定、关闭/切换原文档、空实例拒绝和独立结果展示。新增注册读取挂起时结构/提取仍可用，连接过期、网络失败及超时保留人工标记，重连可继续；已执行但响应或结果回读丢失时保留标记并要求重新分析取回实际角色，明确结构变化仍使标记失效。浏览器证据不等于 WPS 内嵌窗口的下载/文件选择可用。
- Node CLI 临时端口自检通过，校验配置读取并逐一检查静态白名单资源；候选自检不读取尚未切换的正式注册文件，注册状态由环境检查单独报告。损坏配置自检失败且原文件保留。Swift 历史设置存储/安装事务检查保留并通过。
- 补充失败路径回归：旧服务端口与 TIME_WAIT 释放、坏 Node 服务重新初始化/回退/卸载、本次兼容设置快照、保留后来新增的其他插件注册、切换前文件基线与 WPS 状态复查；文档切换往返和编辑撤销后的旧会话拒绝执行；页眉页脚各文字段字体/字号与段距/行距漏检修复。
- 按引用清理 10 个退役探针、旧安装/卸载脚本和未使用 PNG，删除无注册 Ribbon 模板回调及冗余样式/重复更新，队列领取状态改由现有 pending/busy 推导。退役回调的独有测试删除，实际模板切换仍由设置页回归覆盖。保留迁移、保护校验、撤销、旧 Swift 源码及历史资产。
- 初始化入口失败时明确显示“未完成”，在真实 PTY 中确认按回车前保持窗口、之后保留原退出码；四入口共用同一启动脚本。候选构建号检查区分尚未切换与已装服务故障，不把旧服务标成新版。
- 用户完全退出 WPS 后，本机 Node 22 初始化成功；回读确认运行构建号、绝对 Node 路径、登录项和插件注册，原设置与本次初始化前的备份字节一致。重新打开 WPS 后，真实设置窗口显示“文档结构／环境检查”和“识别与分页”入口；合成通知的一次只读分析识别出标题、正文和落款。
- 真实多实例检查发现：其他 WPS 窗口的心跳会取消结构分析。已修复为按插件实例隔离命令、心跳、字体和结果，面板绑定打开时的文档；其他实例不能领取或取消目标请求，过期实例不回退到其他窗口。修复已在用户退出 WPS 后安装，设置字节保持一致；真实结构页完成合成通知分析、人工标记“保持原样”和改动清单。两个已连接实例同时操作的验收仍待完成。
- 合成通知真实 WPS 回读通过：分页布尔属性读回 -1/0，大纲级别 1/9/10；标题、称谓、正文、落款识别及首个中文冒号段缩进正确。排除段落完整属性和正文 XML 不变；必要空段只修改分页链接。首次修改 9 段，重复预览和排版均修改 0 段，一次撤销恢复正文、段落、页面、对象和页眉页脚实际内容及格式。精确“华文中宋”和“仿宋”可用；测试不写入客户文档。
- XML 比对边界：页眉页脚 Flat OPC 的共享字体表追加字体，实际内容片段及标量属性一致；重复和撤销后的完整导出设置出现新增 embedSystemFonts 节点，原因尚未确定。因此不声称整个导出 XML 或全部设置字节恢复。本机应用元数据为 WPS 12.1.28496、macOS 26.6.2、arm64；桥接报告 COM 版本 12.0，不能用它证明完整 WPS 构建版本。

- 已准备通知、合同与九级标题/编号重启、带附件长段及多节四份合成文档。准备文件不构成排版通过。
- 候选源码使用独立分支和 [草稿 PR #1](https://github.com/DaLang77/wps-local-formatter/pull/1)。实例隔离提交 `e8ecf18` 的 Node 22、macOS/Node 24 和浏览器三个 [GitHub CI job](https://github.com/DaLang77/wps-local-formatter/actions/runs/37063831269) 均通过；后续提交结果以 PR 检查为准。尚未合并或创建新 Release。

## 真实 WPS

全部测试使用合成文档，不对案件文档执行排版。

- 单页：替换已有页眉页脚，读回「第1页/共1页」，重复执行无修改，一次撤销还原原内容与页面。
- 三页单节：页眉、页脚文字与 PAGE / NUMPAGES 动态域写入；首页隐藏，正文内容保持不变；重复执行无修改，一次撤销恢复。
- 三页多节：每节统一页眉页脚，仅文档首页隐藏，后续节连续编号；重复执行无修改，一次撤销恢复段落、页面及各节页眉页脚。
- 独立开关：仅替换页脚保留页眉与动态页码；仅替换页码保留页脚文字，并支持起始值 5；仅替换页眉成功。
- 复杂保护：页脚含表格时在排版前停止，前后段落、页面、页眉页脚一致。
- 原有合成回归文档：正文、表格、文本框内容不变；重复排版无修改，一次撤销还原。
- 原生安装窗口：本机更新成功；WPS 未退出时正确阻止安装。真实卸载遇到 macOS「其他应用数据」授权等待；等待结束后读回确认注册及登录项已移除，模板保留。安装窗口已加入异步等待提示，避免主窗口失去响应。最终构建再次安装完成；运行中的 build-id 与发布应用一致，注册仅一份，原配置和模板完整保留。
- 实际 WPS 工具栏和设置窗口已打开检查；图标正常，标签与输入框对齐。浏览器补充检查 560 像素窄窗口，无横向溢出。
- 设置页通过界面保存新增页眉文字，服务读回一致；测试结束恢复用户原配置。

实现使用完整 Flat OPC 文档片段。已修复 WPS 将简化 XML 当作文字、插入时额外保留末尾段落两项实测兼容问题。写入后核验，失败尝试整组撤销。
